# 雪线余火

依据《雪线余火-东北抗联沉浸式交互设计》制作的竖屏沉浸式互动叙事作品。素材统一来自 `按规范命名素材/`，构建过程会自动生成适合移动端和离线演示的 WebP 资源。

## 已实现

- 序章：擦霜启封、长按进入记忆。
- 雪线行军：拖动移动、伏低、掩体吸附、雪地足迹、可选记忆物件和路线代价。
- 密营余火：五件物品探索、干粮与棉衣分配、五秒地图记忆。
- 夜越封锁：动态探照灯、边缘暴露、中心持续照射、屏息、短回退与动态容错。
- 守住火种：六秒护火和档案去向选择。
- 山河回响：今昔叠化、选择生成的个人体验档案与史实边界说明。
- 完整支持：断点继续、程序化环境声、静音、字幕、低动态、辅助潜行和安全区适配。

## 运行

```powershell
npm.cmd install
npm.cmd run dev
```

构建离线静态包：

```powershell
npm.cmd run build
```

产物位于 `dist/`。建议通过任意本地静态服务器打开，以保证浏览器模块与音频策略一致。

## 验证

```powershell
npm.cmd run test:e2e
```

测试覆盖 390x844 六章主流程、Canvas 探照灯像素、全部素材加载、1440x900 桌面居中，以及系统低动态和辅助潜行偏好。

## 史实声明

人物、路线与封锁情节为基于东北抗联斗争环境的艺术化合成，不对应单一真实人物或具体战斗。正式参赛前仍需依据纪念馆、档案馆、权威出版物及指导专家意见审校具体年代、装备、馆藏编号和叙事表述。
